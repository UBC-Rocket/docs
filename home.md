Welcome to UBC Rocket's central design documentation. Use the sidebar to browse
by season and team, or the search bar at the top to find anything.

## Seasons

- **2026-27** — current season
- **2025-26** — archive
- **2024-25** — archive

## How this is organized

The sidebar mirrors the folder structure exactly:

```
season / team / project / page
```

Each season is a top-level section. Inside it you'll find one folder per team,
and inside each team you can nest projects and pages as deep as you need — the
navigation follows the folders automatically.

## Contributing

Click the **pencil icon** at the top of any page to edit it on GitHub, or add a
new Markdown file to the right folder in the repo. See the
[contributing guide](/contributing) for details.
