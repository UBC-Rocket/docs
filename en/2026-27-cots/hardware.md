The folder structure mostly follows the avionics bays we have, out of which one of the COTS bays is in the first stage and the rest are in the second stage of the rocket.

## Editting guidelines (Please read)
Please clone this repository and pull from it frequently. **Just have it open whenever you are working on your project**, make edits here of what you do, and save, `git add .` and `git commit -m "commit message"` and `git push` after you are done with you work session.
This way you add changes incrementaly and our documentation stays updated.
For documentation, generally follow these guidelines:
1. Do not change the folder structure
2. Edit your own md file. Typically, I should have already made one for your project. If not, go ahead and make a md file in the relevant folder / av bay
3. When in doubt add justifications
4. Include links as much as you can about things you write about
5. Whenever you can, include system level diagram and visuals. This helps a lot when discussing with others
